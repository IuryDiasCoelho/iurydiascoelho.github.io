# Iury Dias Coelho — Portfólio

Site pessoal desenvolvido para apresentar minha trajetória como estudante de Engenharia de Software, minha experiência profissional no Exército Brasileiro e os projetos que venho construindo ao longo da formação.

🔗 **Site publicado:** [iurydiascoelho.github.io](https://iurydiascoelho.github.io)

## Sobre o projeto

Portfólio construído com HTML, CSS e JavaScript puros (sem frameworks), com identidade visual inspirada em elementos do universo militar — paleta em tons de verde-oliva, cáqui e dourado, textura de camuflagem como plano de fundo e um cartão estilo "condecoração" na seção de experiência profissional.

## Funcionalidades

- **Efeito de digitação** animado no subtítulo do header
- **Menu responsivo** com botão hamburguer para mobile
- **Seção de Experiência** com destaque para o reconhecimento recebido (Referência Elogiosa e Honra ao Mérito), com links diretos para os documentos originais
- **Formação acadêmica** detalhada: disciplinas concluídas (com notas), em andamento e pendentes, extraídas do histórico escolar oficial
- **Projetos** com links diretos para os repositórios no GitHub
- Layout **mobile-first** e totalmente responsivo

## Tecnologias utilizadas

- HTML5 semântico
- CSS3 (variáveis customizadas, Flexbox, media queries)
- JavaScript (Vanilla JS — sem dependências)
- Fontes: [Poppins](https://fonts.google.com/specimen/Poppins) e [Oswald](https://fonts.google.com/specimen/Oswald) (Google Fonts)
- Ícones: [Devicon](https://devicon.dev/)

## Como rodar localmente

Como é um site estático, basta clonar o repositório e abrir o `index.html` no navegador:

```bash
git clone https://github.com/IuryDiasCoelho/iurydiascoelho.github.io.git
cd iurydiascoelho.github.io
```

Depois é só abrir o arquivo `index.html` diretamente no navegador, ou servir a pasta com uma extensão como o *Live Server* (VS Code) para recarregamento automático.
